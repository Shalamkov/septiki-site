# Сайт дилера септиков «СЕПТИК·ДИЛЕР»

Одностраничный сайт продажи и монтажа септиков под ключ. Официальный дилер четырёх заводов-производителей: **Евролос, КИТ (MINTEKO), ТВЕРЬ, Малахит**.

Структура и стиль сделаны по образцу [shtaketvam.ru](https://shtaketvam.ru/): шапка с телефоном и заказом звонка, большой hero-блок, преимущества, каталог с табами по брендам, подбор модели по количеству человек, монтаж под ключ с таблицей цен, рассрочка, отзывы, кейсы, сертификаты, FAQ, форма заявки и футер с реквизитами.

Сайт анимирован: плавное появление блоков при прокрутке, анимированные счётчики статистики, «парящее» изображение в hero, зум фото при наведении, плавное раскрытие FAQ, пульсация кнопки WhatsApp. Если в системе пользователя отключены анимации (`prefers-reduced-motion`) — все эффекты отключаются автоматически.

## Структура файлов

```
septiki-site/
├── index.html      — страница сайта
├── css/
│   └── styles.css  — стили (адаптив, мобильная версия)
├── js/
│   ├── main.js     — интерактив, подбор, формы
│   └── animations.js — анимации: появление при прокрутке, счётчики
└── README.md       — эта инструкция
```

Сайт полностью статический: для работы нужен только любой веб-хостинг, база данных и бэкенд не требуются. Формы отправляют заявку в мессенджер на выбор клиента: **WhatsApp**, **Telegram** или **чат-бот МАКС** — с готовым текстом.

## ⚠️ Что нужно заменить перед запуском

### 1. Контакты (обязательно)

В файле `js/main.js` в самом начале — блок `CONTACTS`:

```js
const CONTACTS = {
  whatsapp: '79107850007',      // номер WhatsApp, без «+» и пробелов
  phoneLink: '+79107850007',    // телефон для tel:-ссылок
  city: 'Смоленская область',   // город / регион работы
  telegram: 'ZHARA869',         // username без @ — заявка откроется в t.me/ZHARA869
  max: '',                      // ← ссылка на чат-бот МАКС вида https://max.ru/join/...
  email: 'info@septik-profi.ru' // e-mail (домен свободен — зарегистрируйте и заведите ящик)
};
```

Пока `telegram` / `max` пустые — формы подскажут клиенту, что ссылка не настроена (тост). Как только заполните — плавающие кнопки Telegram и МАКС появятся на сайте автоматически.

В файле `index.html` также замените:
- секция «Контакты»: плейсхолдеры-ссылки Telegram и «Чат-бот МАКС» (ищите комментарии `TODO`);
- футер: реквизиты (ИНН / ОГРНИП), название компании;
- верхняя полоса и футер: телефоны уже заполнены (+7 910 785-00-07, +7 920 303-50-07).

### 2. Название компании

Логотип «СЕПТИК·ДИЛЕР» встречается в шапке и футере (`index.html`) — замените на своё название.

### 3. Цены и модели (по необходимости)

- Цены в карточках каталога и таблице монтажа — в `index.html`.
- База для «Подбора септика» — в `js/main.js` (объект `MODELS`): можно добавлять/менять модели и цены.

## Изображения

Изображения товаров и фото монтажей подключены напрямую с сайтов производителей (горячие ссылки). Перед запуском рекомендуется:
1. Скачать все изображения (открыть ссылки в браузере и сохранить).
2. Положить в папку `img/`.
3. В `index.html` заменить `src="https://..."` на локальные пути (`img/photo-1.jpg`).
4. Заменить фото «Наших работ» на собственные фотографии монтажей — это повысит доверие клиентов.

## Публикация

Варианты бесплатно/дёшево:
1. **GitHub Pages** — загрузите папку `septiki-site` в репозиторий, включите Pages (Settings → Pages → Deploy from branch). Сайт будет по адресу `https://ваш-логин.github.io/имя-репозитория/`.
2. **Netlify / Vercel** — перетащите папку в интерфейс netlify.com, сайт заработает сразу.
3. **Обычный хостинг** (reg.ru, timeweb и т.п.) — загрузите файлы в папку `public_html`/`www` по FTP.
4. Подключите свой домен (например, `septiki-вашгород.ru`) — DNS-настройки зависят от хостинга.

## SEO

Базовый SEO уже заложен: `<title>`, `meta description`, семантические теги. Для продвижения добавьте в `index.html`:
- Яндекс.Метрику (счётчик в `<head>`);
- регистрацию в Яндекс.Бизнес и 2ГИС со ссылкой на сайт;
- страницы под ключевые запросы «септик купить [город]», «установка септика [город]».

## Формы и мессенджеры

- В каждой форме клиент выбирает канал: **WhatsApp** (открывается `wa.me` с готовым текстом), **Telegram** (`t.me/логин?text=...`) или **чат-бот МАКС** (открывается ссылка, текст заявки копируется в буфер обмена).
- Плавающие кнопки Telegram и МАКС появляются автоматически, как только заполнены `CONTACTS.telegram` и `CONTACTS.max`.
- E-mail `info@septik-profi.ru` — домен `septik-profi.ru` свободен (проверено по DNS 16.08.2026). После регистрации домена и создания почтового ящика замените адрес при необходимости.

## Известные ограничения

- Формы не сохраняют заявки на сайте — они открывают мессенджер. Если нужна заявка на e-mail или в базу — доработать под бэкенд/сервис форм (например, Formspree, телеграм-бот).
- Рассрочка (Сплит/Халва) — партнёрские виджеты банков подключаются отдельно (по ссылке на Халву с shtaketvam.ru — замена на ваш партнёрский аккаунт).
